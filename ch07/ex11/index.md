◆pushの平均時間計算量　o(1)
計算を簡単にするため、初期サイズを1とする
pushをn回呼び出すと、再配置がlog_2 n - 2回発生する
（配列の要素数がnのとき、再配置はlog_2 n - 2 回発生している）
各再配置で要素のコピーは$`2^0, 2^1, 2^2, 2^3, ..., 2^{log_2 n}`$ 回発生する（pushする前の要素数がこの数）ので、総和は
2^0 + 2^1 + 2^2 + ... + 2^{log_2 n} = 2^{(log_2 n) + 1} - 1
平均すると、
(2^{(log_2 n)+1}-1) / n = {2^(log_2 n) * 2^1}/n -1/n
=(n * 2)/n - 1/n 
=2-1/n
nが十分に大きいと1/nは無視でき、定数項のみ残るため、o(1)
